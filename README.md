# Jimak's Mini Storacha DApp

A decentralized application (dApp) that allows users to seamlessly upload files directly to the decentralized web using the Storacha network. 

## 🌟 Features
* **User Authentication:** Secure, passwordless login via email to create a decentralized identity (Space).
* **Decentralized Storage:** Uploads files directly to the Web3 network without relying on centralized backend servers.
* **Instant CID Generation:** Automatically generates Content Identifiers (CIDs) and shareable IPFS Gateway links for uploaded files.

## 🛠️ Tech Stack
* **Frontend:** React, Vite
* **Web3 Integration:** `@storacha/client`
* **Deployment:** Vercel

## 🔗 Live Demo
Check out the live application here: https://jimak-s-storacha-dapp.vercel.app

## 💡 How it Works
This project uses the Storacha JavaScript client to interact with the decentralized network. The browser generates an unextractable RSA key for security, ensuring the user maintains full control over their uploads.
